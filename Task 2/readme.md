# 🧮 CodeAlpha Calculator

A modern and responsive calculator built using **HTML**, **CSS**, and **JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

---

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage Operation
- 🗑️ Delete Last Character (DEL)
- 🧹 Clear Display (AC)
- ⌨️ Keyboard Support
- 📱 Fully Responsive Design
- 🎨 Modern Glassmorphism User Interface
- ⚠️ Error Handling for Invalid Expressions

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run the Project

1. Download or clone this repository.

2. Open the project folder in **Visual Studio Code**.

3. Install the **Live Server** extension (if not already installed).

4. Right-click on **index.html**.

5. Click **Open with Live Server**.

The calculator will open in your default web browser.
