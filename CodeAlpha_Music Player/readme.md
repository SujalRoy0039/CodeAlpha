# 🎵 Music Player

A modern and responsive **Music Player** built using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

The application provides an elegant user interface with music playback controls, playlist support, progress tracking, and volume adjustment.

---

## 🚀 Features

- ▶️ Play and Pause music
- ⏭️ Next and Previous song controls
- 🎵 Playlist support
- 🖼️ Dynamic album cover display
- 💿 Rotating album cover while music is playing
- ⏱️ Real-time progress bar
- ⏳ Current time and total duration display
- 🔊 Volume control
- 🎶 Automatic playback of the next song
- ⌨️ Keyboard shortcuts
- 📱 Fully responsive design
- 🎨 Modern Spotify-inspired UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ▶️ How to Run

1. Download or clone this repository.

```bash
git clone https://github.com/your-username/CodeAlpha_MusicPlayer.git
```

2. Open the project folder.

3. Add your music files inside the **songs** folder.

4. Add album cover images inside the **images** folder.

5. Open **index.html** in your browser.
